Milling and turning stock removal

One Stock Removal button and one Stock dialog for milling and turning. Review remaining material using the executed toolpath and configured tool geometry, with settings for the active machining mode.

3D milling stock removal

Automatic or manual X/Y/Z box bounds, machining allowance and five Accuracy levels. Flat, face, ball, corner-radius and tapered-ball cutter profiles determine the cut surface.

Play/Pause, stepping and rewind synchronize the remaining stock with the tool position. Stock and machined-surface colors are configurable. The current machining stage can be exported as STL.

Turning path and stock examples

Three-axis milling removal and surface rendering run on the GPU and require OpenGL 4.3. The milling model supports a box blank and vertical cutters. Rotary/TCP removal, undercuts and subtraction from imported STL solids are not supported.
