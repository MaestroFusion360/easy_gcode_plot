Export the execution.

Choose NC output or DXF geometry. Keep the source dialect in FULL, or serialize the resolved execution for a supported target with EXPANDED. HEIDENHAIN and SINUMERIK turning FULL normalization are unavailable; use Save/Save As to preserve their source text.

Control the output

Choose the target controller, arc representation, precision, numbering and program wrappers. The desktop, CLI and batch export use the same calculation and output rules.

In EXPANDED EXECUTION, use a built-in or saved user post, or import a JSON profile for the current machine type; importing keeps the original file unchanged.

Postprocessors for your controller

Eight built-in export posts are available:

  • Milling: FANUC, SINUMERIK 840D ISO-M (G291), SINUMERIK 840D native, and Heidenhain iTNC 530.
  • Multi-axis milling: FANUC and SINUMERIK 840D native.
  • Turning: FANUC lathe A and FANUC lathe B.

The Heidenhain post outputs BEGIN/END PGM, TOOL CALL, L/FMAX, CC with C/CP, CR and drilling cycles in EXPANDED.

Customize posts in Settings → Options → Postprocessors. Built-in posts are read-only: save a copy to edit it, and the copy appears in Export alongside them. The profile is checked before saving.

Five-axis FANUC ↔ SINUMERIK export is experimental. Its compensation, kinematics and verification limitations are listed in the conversion details.
