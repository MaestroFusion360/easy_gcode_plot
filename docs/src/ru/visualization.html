02 / ПРОСМОТР ТРАЕКТОРИИ

Обработка с поворотными осями

Просматривайте индексную обработку и поддержанные непрерывные движения rotary/TCP. Выбирайте кинематику станка для FANUC G68.2/G53.1, SINUMERIK CYCLE800 и поддержанных пятиосевых программ AC/BC.

Импортированные STL-модели служат визуальным ориентиром. Полная проверка столкновений станка пока не моделируется.
