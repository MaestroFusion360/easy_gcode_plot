3D milling stock removal

Material-removal simulation for three-axis milling using the executed toolpath and configured cutter geometry.

Stock setup and playback

Automatic or manual X/Y/Z box bounds, machining allowance and five Accuracy levels. Flat, face, ball, corner-radius and tapered-ball cutter profiles determine the cut surface.

Play/Pause, stepping and rewind synchronize the remaining stock with the tool position. Stock and machined-surface colors are configurable. The current machining stage can be exported as STL.

Milling stock settings and limitations →

Removal and surface rendering run on the GPU and require OpenGL 4.3. The model supports a box blank and vertical cutters. Rotary/TCP removal, undercuts and subtraction from imported STL solids are not supported.
