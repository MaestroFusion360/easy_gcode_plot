TOKENS AND VARIABLE STATE

Inspect program lines and controller variables

Follow diagnostics and recorded variable values in one inspector for FANUC, SINUMERIK and HEIDENHAIN iTNC.

Find the relevant blocks

Open CNC Functions → Tokens/Variables. The Tokens tab shows source lines, parsed words, support status and diagnostics. Select All, Warnings or Errors and search for text such as T1 M6 without recalculating the program. The footer shows the filtered row count; copying and CSV export respect the filters.

Follow values during playback

The Variables tab reads existing execution snapshots at the current playback position. Controller, source line and execution occurrence identify the displayed state, including repeated blocks in loops and subprograms. Inspect values or export them to CSV without running the program again. Stale execution must be updated before viewing its variable state.

FANUC: #

Inspect numbered Macro B variables such as #1 and #100, plus named variables such as #<NAME>. Available for turning and milling execution.

SINUMERIK: R

Inspect native parameters such as R1 and R10, together with recorded named scalar variables. Native identifiers remain distinct from FANUC Macro B identifiers.

HEIDENHAIN iTNC: Q

Inspect Klartext Q, QL and QR parameters captured during execution, using their controller names.

A clean Tokens table does not guarantee complete execution or a valid toolpath. Check the execution status and diagnostics as well.
