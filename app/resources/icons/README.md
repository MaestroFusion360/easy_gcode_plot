# Icons

This directory contains both original project icons and third-party icons, including some sourced from [Icons8](https://icons8.com).

**Not all icons are from Icons8.** Some were created by the project author. Attribution to Icons8 applies only to icons actually sourced from Icons8.

Icons8 license and usage terms: <https://icons8.com/license>

The origin of each individual icon is not documented in this file.
