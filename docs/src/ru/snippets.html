Сниппеты

Редактируемые фрагменты программ, фрезерные и токарные циклы для FANUC, SINUMERIK и HEIDENHAIN iTNC 530.

Готовые фрагменты для вашей программы

Выберите группу или найдите нужный шаблон по названию в панели «Сниппеты». Нажмите «Вставить», заполните поля — готовый фрагмент появится в программе. Всю вставку можно отменить одним действием.

Кнопка «Редактировать» открывает библиотеку шаблонов. В ней можно изменять готовые фрагменты, создавать свои и добавлять поясняющие схемы. Шаблоны для разных стоек хранятся отдельно.
