Milling tool types — 9 options

On the milling tab, add a tool to the library, then choose its type and dimensions. The names below match the editor list. All types have a diameter, flute length and body length; length to holder is the sum of the two lengths. Enter dimensions in millimetres or inches.

Editor type Shape Specific settings
Flat Mill Flat-ended end mill Diameter and lengths
Bull Mill Corner-radius end mill Corner radius, at most half the diameter
Ball Mill Ball-ended mill Ball radius automatically equals half the diameter
Taper Ball Mill Tapered mill with a spherical tip Ball-tip diameter and taper angle
Face Mill Face mill Shank diameter smaller than head diameter
Slot Mill Mushroom cutter Shank diameter and flute length
Chamfer Mill Chamfer cutter Flat-tip diameter and chamfer angle
Drill Drill Point angle
Tap Tap Diameter and lengths

For face and mushroom cutters, flute length defines the head height. Older records with a single total length retain a separate cutting-height field until the split lengths are edited.

Turning tool types — 9 options

In the turning editor, choose a category, machining direction and available type. OD means external machining, ID means internal machining, and Face means face machining. Available types and P tip orientations depend on the selected direction.

Editor type Shape Settings
Diamond 80 80° diamond insert Nose radius, insert size and P orientation
Diamond 35 35° diamond insert Nose radius, insert size and P orientation
Square Square insert Nose radius, insert size and P orientation
Round Round insert Insert diameter, nose radius and P orientation
Triangle Triangular insert Nose radius, insert size and P orientation
Groove Grooving tool Width, nose radius and P orientation; radial or face groove geometry
Thread Threading tool Insert size, profile angle, tip width EX, corner radius RC and P orientation
Drill Drill Diameter, length and point angle
Tap Tap Diameter, length and point angle

The saved library and current-program tools are separate lists. Assign a library entry to a program tool to use its geometry; save an edited program tool to the library for later work. Use the preview to check shape and orientation before saving.
