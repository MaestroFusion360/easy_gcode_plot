CYCL DEF 220/221 DEF-active circular/grid patterns execute the previous supported machining cycle at each position. Explicit Q parameters and R0 are required; no extra CYCL CALL triggers the pattern.

Q cycle continuations, Q208=MAX Cycle parameters are consumed in execution order; symbolic rapid retraction feed is supported for cycles 202/203. Q253 MAX/FMAX selects rapid pre-positioning in cycles 204/205/241/262.
Cycles 7/10 Axis-address datum shifts and XY planar rotation (ROT); zero resets. Datum-table and tilted-plane variants are unsupported.
Cycle 247, Q339=1..6 Selects the application's configured G54–G59 offsets while preserving machine position. Other preset numbers are unsupported.
M140 MB distance / MAX Retraction follows physical machine +Z, mapped through configured table orientation. MAX uses Z from Home (G28) in WCS with Home emulation enabled, in the positive direction only. The approximation emits a warning and blocks NC trace export; physical travel limits are not modeled.
F0, optional / blocks F0 retains geometry with a warning. Optional blocks follow Block Skip settings.
RND / CHF Planar tangent rounding and straight-line chamfers before RL/RR compensation, with block-local feeds.
A/B/C, IA/IB/IC Rotary indexing requires a matching configured profile, including zero angles. Continuous rotary L motion requires active TCP.
PLANE SPATIAL SPA/SPB/SPC, PLANE RESET STAY changes the coordinate frame; TURN solves orientation with two rotary joints. SEQ+/SEQ− select the swivel branch. MOVE and TABLE COORD are unsupported.
M128/M129, FUNCTION TCPM / RESET TCPM Logical tool-tip control on AC/BC tables with PLANE reset. The supported FUNCTION form is F TCP AXIS POS PATHCTRL AXIS. Traces retain start/end tool orientations.
M126/M127, M94 Enable/cancel shortest-path rotary positioning and reduce displayed rotary angles.
M120, U/V/W, tool offsets DL/DR/DR2 Not executed; unsupported operations stop with a source diagnostic. OEM pivot lengths and full machine collision simulation are outside the model.
