# CIMCO Edit 8 и Easy G-Code Plot 1.9.8

**Обозначения:** ✅ — подтверждённая функция в указанном объёме; ⚠️ — частичная поддержка / ограниченная семантика; ❌ — явно отсутствует; **?** — точное поведение CIMCO Edit 8 не подтверждено. **Отсутствие данных о поддержке функции не означает её отсутствие.** «≈» — сопоставимо только в указанном объёме. Сравнивается **CIMCO Edit 8 Backplot**, не CIMCO Edit 2022–2026 и не отдельная CIMCO Machine Simulation. Для CIMCO статусы по SINUMERIK, отсутствующие в руководстве, перенесены из исходной таблицы автора [U]. «Есть команда в фильтре» не означает правильное моделирование геометрии.

[Версия на английском](COMPARISON.md).

## Что изменилось в 1.9.8

- Добавлены фрезерные G74, G76, G87, G89 и синхронные шаги Q для G74/G84. Направление отвода Q и параметры возврата при резьбонарезании задаются в настройках ядра.
- Добавлены native CYCLE85/86/87/89. CYCLE84 поддерживает правую/левую метрическую резьбу и глубокую резьбу VARI=1/2 с DAM/VRT и выравниванием последних шагов. CYCLE88 остаётся неподдержанным.
- Исправлены локальная плоскость окружности Siemens и чистое быстрое индексирование поворотных осей при активном CYCLE800.
- Обе исходные программы Fusion 1001 доходят до M30 с кинематикой `5ax_table_ac`; регрессии проверяют home Z=0 и 500. Без геометрии инструмента компенсация остаётся непроверенной. DC вне 0–360° нормализуется с предупреждением для визуализации; это не подтверждает допустимость таких значений на стойке.
- G92.1 с нулевыми селекторами осей учитывается как preset без физического перемещения. Ручные/G92-сдвиги в модели отсутствуют. G53 и G28 с заданным home поддерживались и раньше.
- Ошибка дуги даёт диагностику, но последующие блоки могут исполняться. Завершённость и корректность результата проверяются отдельно.
