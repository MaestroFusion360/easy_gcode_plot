# Code of Conduct

Easy GCode Plot is a technical project. Discussion should stay professional, specific, and focused on evidence.

## Expected behavior

Participants should:

- discuss code, controller behavior, documentation, and test results rather than attacking people;
- provide reproducible examples when disputing machining or controller semantics;
- distinguish documented controller behavior from assumptions and machine-specific behavior;
- accept technical correction when evidence shows an implementation or claim is wrong;
- keep issue and pull-request discussions relevant to the reported problem;
- respect contributors regardless of experience level, background, identity, or location.

## Unacceptable behavior

The following is not acceptable:

- harassment, threats, personal attacks, or discriminatory language;
- deliberate disruption of issues or pull requests;
- publishing private information without permission;
- knowingly presenting unsafe or fabricated CNC behavior as verified;
- repeatedly ignoring project scope or safety requirements after being asked to stop.

## Enforcement

To report a concern, [open an issue requesting maintainer contact](https://github.com/MaestroFusion360/easy_gcode_plot/issues/new). Link the relevant public discussion if appropriate. For sensitive reports, request a private channel without posting personal information or incident details publicly; wait for the maintainer to provide that channel. Security vulnerabilities follow the [Security Policy](SECURITY.md).

Maintainers may edit, hide, lock, or remove content that violates these rules and may restrict participation when necessary to keep the project usable and safe.

Technical disagreement is welcome. Personal hostility is not.
